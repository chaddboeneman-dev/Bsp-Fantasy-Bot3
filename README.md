# BSP Fantasy Bot

Mobile-first fantasy football dashboard with a split Detroit Lions / Philadelphia Eagles theme.

## Included
- Four league slots
- Bounty Hunters starter roster
- Start/Sit board
- Waiver comparator
- Trade Bot foundation
- ROS rankings
- D/ST planner
- ESPN league ID setup
- BigShow/Billy JSON export/import
- Installable PWA files

## Free hosting
The static version can be hosted free on GitHub Pages. A later server/database step is required for secure private ESPN syncing and automatic shared BigShow/Billy cloud data.

## GitHub Pages
Upload all files to the repository root. Then open repository Settings > Pages and deploy from the `main` branch/root folder.

Never commit ESPN passwords, `espn_s2`, `SWID`, API keys, or other secrets to a public repository.
